# Security policy

## Supported versions

Security fixes are applied to the latest published version of Fyler. Before reporting a problem,
confirm whether it is still present in the newest release.

## Reporting a vulnerability

Do not disclose exploitable details in a public issue.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/gualask/fyler/security/advisories/new>

Include the affected Fyler version and platform, the impact, reproducible steps, and any suggested
mitigation. Do not attach private documents or personal information. A minimal synthetic PDF or
image is preferred when a sample file is required.

If private vulnerability reporting is unavailable, open a public issue requesting a private contact
channel without including vulnerability details.

For ordinary defects that do not have a security impact, use the in-app support flow or
[GitHub Issues](https://github.com/gualask/fyler/issues).
